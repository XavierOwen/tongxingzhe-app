# 个人兴趣比例使用整数分子、分母和基点

状态：**已接受（2026-08-12）**。

关联：Issue #102、Slice 6X；ADR-0060、ADR-0068、ADR-0076；
`ANALYTICS-001`、`ANALYTICS-003`、`ANALYTICS-007`、
`ANALYTICS-010`、`ANALYTICS-012`。

## 决定

个人单次兴趣的五档比例使用同一个有效接触场次分母。每档结果保存整数分子和分母，
并用整数 half-up 规则计算百分比基点：

```text
percentage_basis_points = (numerator * 10000 + denominator ~/ 2) ~/ denominator
```

`10000` 表示 `100.00%`。分母为零时，分子必须为零，百分比基点为 `null`；界面显示
“暂无可计算比例”，不能把空样本显示为 `0%`。整数分数是权威事实，百分比只是一种
确定性展示结果；Flutter 和 PostgreSQL 不使用浮点数交换或重算权威值。

比例值还分别保存未知、拒答、不适用、未回答和排除数。核心兴趣字段在 Drift 和
PostgreSQL 中都只能是非空 `0–4`，所以四种缺失数均有约束证据支持为零。这里的排除数
只表示进入有效接触候选集后又被该比例定义排除的事实，当前同样为零；它不是草稿、
接触尝试和作废记录的生命周期盘点。

既有 `interest_distribution` v1 和 `interest_ordinal_summary` v1 保持不变。新增
`interest_level_ratios` v1 承载五档比例，并继续使用
`localOperational + personalFact`、UTC 半开期间、数据截止和接触场次同步覆盖。

## 后果与边界

五档分子之和必须等于共同分母。页面从版本化结果读取分数和基点，不在 Widget 中除法。
它同时显示分子、分母、百分比和缺失／排除覆盖说明，让使用者可以复算结果。

本决定不定义 `3–4` 合并比例、渠道比例、对象当次反应、关系阶段或后续联系同意比例。
后续联系同意的统计单位和缺失状态不同，必须另建数据来源和版本化指标，不能套用本票的
全零缺失事实。草稿没有可信的实际发生时间，因此本票也不以创建时间猜测生命周期排除数。
