# 匿名分析防止相减反推但暂不加随机噪声

状态：**已被 [ADR-0099](./0099-management-analytics-use-bounded-query-surfaces.md) 取代（2026-08-03）**。

下文保留原决定作为历史记录，不再作为当前隐私保证。阈值、互补隐藏和查询限制只能降低披露风险，不能证明任意查询序列无法重新识别个人或小群体。

匿名统计阈值 `10` 由后端在返回任何图表、导出或 API 结果前执行，App 不会收到被隐藏的精确数值；当小分组被隐藏时，系统同时使用互补隐藏，并限制可分析维度以及时间、区域粒度，检测可能用于反推的连续重叠查询。第一阶段不向安全分组的结果添加随机噪声，仍返回精确值；隐私保护依靠阈值、互补隐藏和防差分查询共同完成，且说明书必须明确该阈值不代表统计显著性或结论可靠性。
