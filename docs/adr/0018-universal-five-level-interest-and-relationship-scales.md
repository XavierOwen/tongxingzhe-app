# 兴趣度与关系阶段统一为五级量表

同行者在全平台统一两套相互独立的五级量表：接触记录保存当下的单次兴趣，项目关系保存长期的关系阶段，两者底层都使用 `0–4`。单次兴趣依据可观察行为定义：`0` 明确拒绝，`1` 互动但无继续意愿，`2` 中性或无法判断，`3` 明确愿意继续，`4` 主动提出或落实下一步。关系阶段依据长期进展定义：`0` 初次建立，`1` 可以联络，`2` 持续互动，`3` 明确推进，`4` 达成项目定义的目标关系。项目可以为每一级配置符合固定语义的显示名称，但不能改变级别含义、顺序或方向；若界面需要显示 `0、2、4、6、8`，由 `stage * 2` 计算，不把该表示存入数据库。统一量表使 SQL 汇总直接可比，同时避免把单次反应误当作长期关系。
