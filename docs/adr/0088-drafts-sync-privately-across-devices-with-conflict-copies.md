# 草稿私有跨设备同步并保留冲突副本

已登录用户的接触草稿默认通过后端同步到本人的其他已登录设备，但每份草稿可由记录者明确改为“仅保存在本设备”，并始终显示当前同步模式与状态。草稿只允许其创建者读写，组织所有者、项目管理员和其他成员均不可见，也不进入分析仓库。关闭草稿跨设备同步不影响正式提交后的正常业务数据同步。

草稿在本地数据库中加密，通过加密传输发送，在云端加密存储，并通过内部 `app_user_id` 进行创建者权限校验。这不宣称端到端加密：后端需要理解问卷版本与结构才能执行同步校验，App 必须向用户如实说明这个边界。

## Consequences

同一草稿如在两台离线设备上分别修改，系统不使用“最后写入胜出”，而是保留两份内容并标记草稿冲突副本，由记录者比较后选择或手动合并。如果一台设备已正式提交，另一台设备的未同步修改不得覆盖正式记录；它保留为私有冲突副本，只能由记录者放弃或明确转化为接触修订。
