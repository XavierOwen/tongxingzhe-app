# 接触记录采用离线优先与 Outbox

状态：**已接受（2026-07-31）**。Outbox 的领取、租约、确认、退避和健康状态由 [ADR-0098](./0098-persistent-outbox-uses-claim-lease-and-ack.md) 细化。

创建草稿、提交接触和查看本人近期记录必须在无网络时正常工作。Flutter 先把数据写入本地 SQLite，并将待同步操作写入 `sync_outbox`；联网后通过后台 API 同步，界面明确区分仅本机、同步中、已同步、冲突和失败。Snowflake 一类分析仓库位于后端链路下游，不能阻塞本地保存或界面更新；同步冲突也不能静默覆盖既有数据。
