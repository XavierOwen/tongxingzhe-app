# 问卷采用草稿、预览与不可变发布

每个推广项目同时只有一个供新建接触草稿使用的当前问卷版本。管理者编辑的是不影响当前正式表单的问卷草稿；发布前必须通过题型、必填、选项和显示规则验证，使用模拟答案完整预览，查看相对当前版本的逐项差异，并完成问卷指标的语义兼容判断。

发布创建一个不可修改的问卷版本，保留发布人、时间和发布说明，并把它设为项目的当前问卷版本。后续修改必须从已发布版本复制出新草稿；即使需要回到某个旧设计，也应从该旧版本复制后发布成新版本，不覆盖、重写或重新解释原版本。

## Consequences

第一版只支持有权操作者明确确认后立即发布，不实现定时发布、灰度发布或让不同使用者同时获得不同当前版本。新版本只自发布后用于新建接触草稿，不静默改写历史记录的问卷引用。
