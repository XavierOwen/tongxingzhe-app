# 个人提醒跟随设备当地时间

个人提醒保存为当地钟点，并在每台提醒设备的当前本地时区触发；用户从芝加哥前往上海后，原定晚上七点的提醒仍在上海当地晚上七点出现，而不是保持芝加哥的绝对时刻。系统同时记录每次实际触发的时区，以便解释历史与处理夏令时变化。

## 可观测性定义

“实际触发”指操作系统首次呈现通知的时间和时区。它不是 App 安排通知的时间，也不是 App 查询通知中心或用户点击通知的时间。

当前通知插件只提供安排 API、活跃通知查询和用户交互回调。它没有 Android、iOS 和 macOS 通用的后台送达回调。因此，现有实现尚未交付实际触发时区历史，不能用查询或点击时间补写。

Issue #50 的[真机 Spike](../spikes/reminder-delivery-and-travel-time-zone.md)负责取得平台证据。证据完成前，本决策的当地钟点合同保持不变，实际触发历史仍是未完成项。
