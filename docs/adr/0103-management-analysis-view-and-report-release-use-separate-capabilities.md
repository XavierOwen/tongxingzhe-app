# 管理分析查看与报告发布使用独立项目能力

状态：**已接受（2026-08-11）**。

关联：Slice 6I；ADR-0007、ADR-0010、ADR-0033、ADR-0034、ADR-0099；`AUTHZ-001`–`AUTHZ-006`、`PRIVACY-001`–`PRIVACY-011`。

管理报告授权必须依次确认活动账号、有效组织、活动组织成员关系、活动项目、明确项目成员关系和所需项目能力。登录身份、当前项目、组织成员身份、项目角色或组织所有权都不能跳过其中任何一层。退出后重新加入会建立新的成员关系；旧项目关系和旧能力不会复活。

第一版固定两个互不包含的能力：`view_anonymous_analytics` 允许读取经过隐私保护的管理分析，`release_management_reports` 允许可信服务端尝试发布正式报告。查看不允许发布，发布也不自动允许读取报告内容。若后续发布端点同时返回报告内容，该端点必须同时检查两项能力。

私有授权解析器依次取得组织、项目和能力事务锁，再使用数据库当前时间完成检查。它不接受客户端时间、报告数据截止时间或任意历史时间。成员和能力区间采用左闭右开。解析器只返回内部用户、组织、项目、三级授权事实、能力和参考时间。调用方必须在同一数据库事务中消费这份证据，不得把它缓存为授权 token。

本决定只固定私有数据约束和授权解析合同。组织邀请、生产成员与能力授予／撤销入口、角色组合、授权变更审计、HTTP、Flutter 界面、报告读取和发布 v2 留给后续 Slice；当前 runtime role 仍不能访问这些表或私有函数。
