# 后续联系同意占比启用使用可审计的当前开关

状态：**已接受（2026-08-13）**。

关联：Issue #122、Slice 6AD-1；ADR-0077、ADR-0123；
`AUTHZ-004`、`AUTHZ-006`、`ANALYTICS-003`、`ANALYTICS-014`。

## 决定

`follow_up_consent_ratio@1` 的项目启用事实使用追加式版本保存。每个版本记录启用值、
预期版本、操作者、幂等请求和数据库记录时间。历史版本不能更新或删除。配置与读取入口每次
重新验证活动账号、个人空间所有者和活动项目；runtime 只能执行窄函数，不能直接访问配置表。

首版采用当前开关语义。当前版本启用时，后续个人查询可以计算项目已有期间；当前版本停用
或项目从未配置时，结果都是 `not_enabled`。停用不删除接触事实或配置历史。启用事实只控制
查询时能否读取指标，不按变更时间裁切指标期间，也不表示接触对象作出了任何同意。

## 后果与边界

同一请求的相同内容重试返回原版本；相同请求的不同内容、过期预期版本和并发竞争失败关闭。
当前开关只适用于可信个人项目。组织项目、管理报告、比例查询、Flutter 缓存、同步和设置界面
需要单独切片。

如果未来需要“只统计启用后发生的接触”，必须新增带生效边界的配置合同和指标版本，不能用
追加历史的记录时间悄悄改变 v1 的期间含义。
