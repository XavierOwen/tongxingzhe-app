# 管理周报使用两个完整 ISO 周

状态：**已接受（2026-08-10）**。

关联：Slice 6；ADR-0062、ADR-0099；`ANALYTICS-001`、`ANALYTICS-004`、`ANALYTICS-007`、`ANALYTICS-012`。

`contact_sessions_by_channel_two_periods` v1 使用 `iso_week_monday_v1` 边界。服务端在项目固定报告 IANA 时区中，取可信数据截止点之前最近两个完整 ISO 周；每周从当地周一 `00:00` 开始，区间为左闭右开。`current` 指两个完整周中较晚的一周，不指正在进行的本周。实现必须分别把三个当地周一午夜转换为 UTC，不得按固定 `168` 小时回推。查看者设备时区和客户端字段不能改变边界。

本决定不规定项目报告时区的保存位置、修改权限、版本历史或生效流程。这些能力进入授权写入切片后另行固定，并须保留已生成报告所用的时区和边界版本。
