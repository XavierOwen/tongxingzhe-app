# 个人与机构的关系使用六类稳定性质

每条个人—机构关系必须且只能选择一种全平台稳定的机构关系性质：

- 任职／代表，如员工、经理或教职人员；
- 所有／治理，如所有者、创办人或董事；
- 学习／参与，如学生、学员或活动参与者；
- 成员／归属，如教会成员或协会会员；
- 合作／服务，如顾问、供应商、合作伙伴或志愿者；
- 其他，并必须填写角色说明。

一条关系只选一种性质以避免统计重复，但同一个人与同一机构可以同时存在多条不同性质的关系。具体角色说明可自由填写“市场经理”、“大三学生”或“小组负责人”等，但默认不用于跨项目统计。项目可以配置显示名称与示例，但不能改变六类的核心含义。

## Consequences

“决策人”、“影响者”或“最终使用者”取决于具体推广项目，不是个人永久的机构身份；这些项目决策角色必须保存在对象的项目关系或场景问卷中，不混入机构关系性质。
