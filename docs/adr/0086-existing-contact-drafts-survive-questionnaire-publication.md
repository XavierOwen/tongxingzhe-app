# 旧接触草稿不因问卷发布而损坏

接触草稿创建时固定绑定当时的问卷版本。App 得知项目发布新版本后，必须明确把旧草稿标为“使用旧问卷版本”，但不静默改写或删除。记录者可以继续按旧版本填写并提交，也可以明确选择草稿升级或放弃；第一版不对此类旧草稿设置强制过期时间，报表依据实际问卷版本标识并分别解释。

草稿升级只能自动复制已明确判定为语义兼容的答案；新问题、新必填项和不兼容答案必须由记录者重新查看与确认，升级确认完成前保留原草稿以便恢复。已在离线设备上正式提交并等待同步的记录已不是草稿，必须按提交时的原问卷版本同步，不因后来的问卷发布而退回或迁移。

## Consequences

新问卷发布后可能仍有少量旧版本记录延后提交或同步，但每条记录都能回溯其问卷版本。这个代价换取了离线可靠性，并避免强制迁移导致漏填、误填或草稿丢失。
