# 删除账号不抹除组织拥有的历史事实

修订说明（2026-09-07）：下文 Firebase 是 [ADR-0025](./0025-use-firebase-authentication-for-production-identity.md) 时期的认证商名称，已由 [ADR-0096](./0096-use-supabase-auth-with-cognito-fallback.md) 取代；当前应理解为所配置认证商的外部身份。以下恢复期、清除和组织历史保留要求不变。本 ADR 不表示账号删除流程中的认证商操作、数据库清除和本地清除已经实现；执行合同仍需由 Slice 7 补齐。

账号删除申请设三十天恢复期；期满后删除 Firebase 身份、用户资料、个人空间、个人反思及本地敏感缓存，并撤销全部成员关系和跟进分配。组织拥有的接触事实与共享跟进内容继续保留，但作者替换为不可反查自然人身份的“已删除成员”标识；唯一组织所有者必须先转让所有权或删除组织。
