# 兴趣子集比例使用独立版本化指标

状态：**已接受（2026-08-12）**。

关联：Issue #104、Slice 6Y；ADR-0060、ADR-0061、ADR-0068、ADR-0076、
ADR-0117；`ANALYTICS-001`、`ANALYTICS-003`、`ANALYTICS-007`、
`ANALYTICS-010`、`ANALYTICS-012`。

## 决定

个人单次兴趣另行注册 `interest_3_4_ratio` v1 和 `interest_0_ratio` v1。
前者计算兴趣等级 `3` 或 `4` 的有效接触场次数，后者计算兴趣等级 `0` 的场次数。
两者使用同一期间的全部有效接触场次作为分母。

每个指标使用独立的 `SubsetRatioMetricValue`。这个值保存一个稳定标签、整数分子、
整数分母、未知、拒答、不适用、未回答、候选内排除数和 half-up 百分比基点。
它要求分子不大于分母，但不要求不同指标的分子相加等于分母。

既有 `RatioMetricValue` 继续表示穷尽且互斥的比例分档。它的全部分子之和仍必须等于
共同分母。不得为复用该类型而添加没有产品语义的 `1–2` 展示指标，也不得在 Widget
中从五档比例临时相加或重新除法。

## 后果与边界

两个派生比例与五档比例共享有效接触候选集、UTC 半开期间、数据截止、同步覆盖和
`personalFact` 隐私状态。分母为零时，分子必须为零，百分比为 `null`。页面显示
`0 / 0` 和“暂无可计算比例”。

核心兴趣仍受非空 `0–4` 约束，所以缺失和候选内排除数有 schema 证据为零。草稿、
接触尝试和作废记录在候选集之前排除，不进入 `excluded_count` 生命周期盘点。

本决定不定义兴趣算术指数、对象当次反应、关系阶段、阶段变更或后续联系同意比例。
这些指标具有不同统计单位或缺失规则，必须使用各自的数据来源和版本化合同。
