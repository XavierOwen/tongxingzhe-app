# 动态分析重算，正式报告使用版本化快照

动态分析始终使用当前有效数据重新计算，并显示最后更新时间及影响当前时间范围的补录、修订和作废数；对外保存或导出的正式报告则使用报告快照，固定数据截止时间、统计定义、问卷版本与兼容映射、区域版本、时区和计算版本。后续数据变化不静默改写旧快照，而是生成与原报告互相链接的更正版报告；旧报告标记已被取代但仍可审计，除非账号、组织或数据依已确认的删除规则必须清除，快照不得成为绕过删除的副本。

当前第一阶段快照冻结已经过隐私保护的报告输出，并记录生成时的运营 change sequence。固定报告版本与查询指纹标识当前计算合同；未参与当前渠道报告的问卷兼容和区域视图不适用。它不把当前投影改造成可按旧水位重放的历史投影。普通产品操作不能更新或删除快照；未来更正版、账号删除和组织删除必须使用单独设计的受审计流程，不能通过关闭发布判定或直接改写旧快照完成。
