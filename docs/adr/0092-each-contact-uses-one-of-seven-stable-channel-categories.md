# 每条记录使用七类稳定渠道中的一类

每条接触记录或接触尝试必须且只能归入一个全平台稳定的渠道类别：

- 面对面；
- 语音通话；
- 视频通话；
- 即时文字互动，即双方当时正在实时交流；
- 异步消息，包括短信、邮件、私信和语音留言等非实时往来；
- 混合渠道，即同一连续互动场次实质使用了多个渠道；
- 其他直接渠道。

项目可以在稳定类别下配置可选渠道明细，例如 WhatsApp、Zoom、电话外呼或校园摊位，并可为稳定类别配置显示名称与示例，但不能改变七类的含义。选择“其他直接渠道”时必须填写简短明细，避免“其他”成为不可解释的统计桶。

## Consequences

同一连续互动从文字立即转入电话时，它仍是一个场次并归入混合渠道；隔数小时或数天后发起的新联络则另建接触或尝试。混合渠道如包含面对面互动，必须记录具体线下地点；纯线上混合渠道的接触地点为 `N/A`。指标按稳定渠道类别让每条记录只计一次，渠道明细只在明确兼容的项目内分析。
