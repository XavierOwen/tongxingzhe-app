# 问卷回答明确区分五种状态

每道场景问题必须区分五种回答状态：“已回答”携带符合题型的真实值；“未知／无法判断”表示问题适用但记录者不知道；“拒绝回答”表示问题适用但对方明确不愿回答；“不适用”表示本次没有该问题所描述的情形；“未回答”表示问题适用但记录者没有填写。必填题不能以“未回答”提交，但项目可以逐题决定是否允许“未知”、“拒绝回答”或“不适用”。

被问卷显示规则跳过的问题由系统判定为“不适用”，并保留“规则跳过”这个原因，不携带旧答案。这五种状态不得用空字符串、`-1` 等哨兵值或普通选项代替，以免把“否”、“不知道”和“没填”混为同一件事。

## Consequences

统计指标必须为每种回答状态明确规定是进入分子、分母还是排除，并在报表中分别显示未知、拒答、不适用和未回答的数量，不自动合并或填补。例如“是否同意后续联系”的“否”是已回答的真实值，不能与未询问、拒绝表态或不适用合并。
