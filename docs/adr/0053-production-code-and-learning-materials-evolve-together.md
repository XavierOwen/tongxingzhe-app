# 正式代码与学习资料共同演进

项目只维护一套可正式上线的生产代码，不另建与真实 App 脱节的教学 Demo；一份与当前代码对应的完整开发说明书，负责向零基础读者解释设计原因、内部流程、Flutter 与 SQL 的用法及取舍，使读者能从头构建一个同类 App。说明书必须详解统计口径、公式、分子与分母、排除规则、时间归属、匿名阈值、数学假设与解释边界，并把它们对应到 Flutter 代码、SQL 和可复算的测试。所有手写业务代码都以中文注释为主：业务函数说明用途、参数来源、返回值和副作用，复杂的统计、SQL、迁移、权限、同步与冲突逻辑按需逐步注释；使用稳定的类、函数和变量名表达来源，不引用会随编辑失效的固定行号，也不手工注释自动生成文件。相关行为、架构、数据库结构或统计口径变更时，对应代码注释、说明书和统计测试必须一同更新。
