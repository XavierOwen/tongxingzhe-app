# 对象当次反应只统计当前已填写关联

状态：**已接受（2026-08-12）**。

关联：Issue #106、Slice 6Z；ADR-0001、ADR-0060、ADR-0061、ADR-0068、
ADR-0070、ADR-0076、ADR-0116 至 ADR-0118；`TARGET-004`、
`TARGET-006`、`TARGET-007`、`TARGET-013`、`ANALYTICS-001`、
`ANALYTICS-002`、`ANALYTICS-007`、`ANALYTICS-012`。

## 决定

`target_response_distribution` v1 的统计单位是“已填写对象当次反应的接触对象
关联”，不是接触场次、触达人数或去重对象。候选集只包含个人可信 scope、UTC 半开
期间内当前有效已提交接触的当前 revision。一个接触有多个已填写关联时，每个关联各
计一次；旧 revision、草稿、接触尝试和作废接触不进入候选集。

`response_level` 的 `0–4` 使用与单次兴趣相同的固定语义，但两项事实分开存储和
统计。`NULL` 表示这条当前关联没有填写反应，不能改写成等级 `2`，也不进入五档
分母。当前关联中的 `NULL` 数量作为 `unanswered_count` 与分布一起返回，使填写
覆盖可见。机构关联只有在明确确认代表机构表态后才能写入非空反应；分析层不从
个人反应、场次兴趣或关系阶段推断机构反应。

## 后果与边界

指标值按接触对象关联计数，而当前本地 Outbox 只能可靠报告相关接触场次是否待同步。
因此个人 `MetricResult` 的 `syncCoverage` 继续明确标为接触场次；不得从待同步场次
推导“已同步关联数”或“已同步反应数”。

对象匿名化会删除 PII，但保留已去身份化的接触对象关联事实。个人聚合只读取
`contact_id + current_revision + response_level`，不返回对象 ID，也不依赖对象当前
姓名、分配或生命周期。管理展示、对象类型拆分、关系阶段、阶段变更、后续联系同意
比例、趋势和 warehouse 新指标均不属于本决定。
