# 未获回应的直接联络是接触尝试

针对明确个人或明确小组的直接联络，如无人接听的电话、尚未获得回应的一对一消息或邮件、无人应门的敲门，记录为独立的接触尝试，而不是接触记录。接触尝试可用于本人回顾已采取的行动，但其触达人数为 `0`，不填写单次兴趣，不改变关系阶段，也不计入有效接触次数或每周接触目标。

如果对方后来回应并开始实际互动，系统新建一条真正的接触记录，并可选关联原接触尝试，不把原尝试静默改写成接触。广告投放、群发宣传、资料准备和通勤既不是接触，也不是接触尝试，因为它们没有针对明确对象发起直接联络。

## Consequences

接触尝试与接触记录必须分开存储和统计，界面、指标目录与学习说明书都必须明示区分“尝试联络”和“已发生互动”，不得通过合并总数制造更高的接触成果。
