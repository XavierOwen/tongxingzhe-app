# 接触填写优先核心事实并渐进展开

快速记录不使用把所有字段平铺在一张长表单上的方式，也不强制简单接触经过多页向导。页面顶部固定显示当前项目与草稿绑定的问卷版本，首屏优先呈现必需的接触核心事实：实际发生时间、接触渠道、具体线下地点与区域或明确的 `N/A`、触达人数，以及场次整体的单次兴趣 `0–4`。

核心事实之后按需展开三组内容：“项目问卷”在存在当次必填题时自动展开并显示完成度；“对象与跟进”用于选填接触对象关联、对象当次反应、后续联系同意与跟进事项；“个人记录”只容纳记录者私有的个人反思和个人生理信号。接触默认保持匿名，姓名、联系方式等可识别资料只在用户主动进入对象流程时写入推广对象，不写入接触记录。

## Consequences

页面底部固定显示草稿自动保存状态与“正式提交”；验证失败时直接定位到缺失项。简单匿名接触不需额外确认页，复杂内容仍可在提交前展开查看摘要。手机使用单列渐进表单，宽屏可使用双栏或“表单＋摘要”布局，但字段顺序、验证与数据含义保持一致。
