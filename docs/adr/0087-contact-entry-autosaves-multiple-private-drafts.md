# 接触填写自动保存多份私有草稿

仅打开空白接触页不创建草稿；用户首次实际填写、选择或明确开始记录后，App 创建接触草稿，并在后续有意义的修改、页面切换、App 进入后台或意外中断前自动保存。界面必须反馈“正在保存”、“已保存”或保存失败，不把保护草稿的责任交给用户反复点击手动保存。

同一用户在同一设备上可以同时保留多份接触草稿，包括属于不同项目的草稿。草稿列表至少显示项目、接触发生时间、最后修改时间、问卷版本与完成情况。空白页可自动丢弃；已有内容的草稿只能由记录者明确放弃，并提供短暂撤销。

## Consequences

接触草稿只对记录者本人可见，不进入接触次数、个人目标进度、项目统计或管理分析。只有记录者明确点击正式提交并通过完整验证后，草稿才转为不可直接覆盖的接触记录；离线正式提交则立即产生本地接触事实并进入同步队列，不继续当作可自由编辑的草稿。
