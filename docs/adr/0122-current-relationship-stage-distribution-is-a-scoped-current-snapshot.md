# 当前关系阶段分布使用受限当前快照

状态：**已接受（2026-08-13）**。

关联：Issue #114、Slice 6AC-0；ADR-0018、ADR-0019、ADR-0026、
ADR-0061、ADR-0074、ADR-0075；`PII-001`–`PII-005`、
`ANALYTICS-007`、`ANALYTICS-010`–`ANALYTICS-012`。

## 决定

个人当前关系阶段分布的统计单位是去重的“推广对象 × 项目”。每个关系最多计一次，
不按接触、revision 或分配计数。个人候选集只包含可信当前项目中，查看者仍有活动分配、
对象状态为 `active`，且项目关系生命周期为 `active` 的关系。分配是个人可见范围，
不是关系的一部分；结束分配会把关系移出该查看者的结果，但不会改变共享关系本身。

`paused` 和 `ended` 不进入默认五档。暂停关系仍是保留中的项目关系，但它不属于“当前
跟进阶段”；需要展示时必须作为独立生命周期状态，不能默默混入 `0–4`。匿名化会结束
活动关系和分配，所以匿名化对象不进入当前分布。关系阶段仍固定为 `0–4`，生命周期
不得编码为负数阶段。

结果使用数据库或本地一致性读取确定的 `snapshot_as_of_utc`。调用者不能把任意历史时间
传入当前快照查询。这个时刻只说明何时判断当前状态，不等于服务器数据截至时间，也不
证明可以重建过去。历史某一时点的分布必须另行组合关系 revision、分配有效区间和对象
匿名化事实；当前投影和今天的分配不能回填历史。

本地个人分析后续使用不含姓名、联系方式或备注的最小关系投影，并按身份、workspace
和项目隔离。它不能为统计而遍历或解密七十二小时 PII vault。同步覆盖以对象 × 项目关系
为单位，分别报告总数与待同步数；覆盖或授权新鲜度未知时，页面不能声称结果已同步。
来源新鲜度与当前快照时刻必须分开表达。

## 后果与边界

完整 Slice 6AC 需要为指标目录增加对象 × 项目统计单位和当前快照时间口径，并设计不强制
使用接触 `MetricPeriod` 的结果合同。它还需要最小 Drift 投影、同步边界、PostgreSQL 窄
读取和个人页面。6AC-0 只固定合同和共享 synthetic fixture，不注册生产指标，也不交付
上述数据路径。

管理阶段分布需要独立授权和匿名保护。阶段变更、历史 as-of、趋势、导出、warehouse 和
后续联系同意占比不属于本决定。
