# 群体接触分开记录场次兴趣与对象反应

每条接触记录保留一个必填的 `0–4` 单次兴趣，表示整个互动场次当下的总体可观察反应；每个已识别的接触对象关联还可以选填同一量表上的对象当次反应。未识别参与者不创建个人评分，也不得把场次整体分数推断为任何对象的个人反应，以同时保留快速匿名记录与可识别对象的精确跟进信息。

## Consequences

单次兴趣分布继续以有效接触记录为单位；对象当次反应必须作为另一个指标，以已明确填写反应的接触对象关联为单位。两种分布不得合并：例如一场群体接触的单次兴趣为 `2`，而已识别对象 A 和 B 的当次反应分别为 `4` 和 `1`，前者只计一个场次 `2`，后者则分别计入对象反应分布。
