# 问卷显示使用受限的声明式规则

场景问卷可以使用受限的声明式规则显示或跳过问题：一个问题只能引用同一问卷版本中排在它之前的问题，因此不会形成循环依赖。是／否和单选可判断等于、不等于或属于某些选项，多选可判断包含或不包含选项，数字和日期可比较大小、相等或范围，文本只可判断已填写或未填写。多个条件只支持一层“全部满足”或“任一满足”，不允许任意嵌套、Dart、JavaScript、公式或 SQL。

被规则隐藏的问题当次视为不适用，无需回答，也不得把旧答案提交进正式接触记录。如果用户修改前置答案后导致已答问题被隐藏，App 必须明确提示将清除哪些答案，并提供短暂撤销。必填只对当次可见的问题生效；隐藏不构成安全边界。

## Consequences

问卷显示规则随问卷版本固定。Flutter 离线端负责即时显示与清理草稿答案，后端使用同一规则重新计算并拒绝必填缺失、类型不符或夹带隐藏答案的提交，以保证离线与云端结果一致。
