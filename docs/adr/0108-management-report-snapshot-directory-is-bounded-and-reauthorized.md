# 管理报告快照目录固定上限并逐次重新授权

状态：**已接受（2026-08-11）**。

关联：Slice 6N；ADR-0099、ADR-0103、ADR-0105 至 ADR-0107；`AUTHZ-001` 至 `AUTHZ-006`、`ANALYTICS-007` 至 `ANALYTICS-014`、`PRIVACY-001` 至 `PRIVACY-011`。

管理报告快照目录使用显式项目 ID，返回至多 20 份具有成功 v2 发布来源的不可变快照元数据。结果固定按数据截至时间、发布时间和快照 ID 降序排列。目录不接受筛选、分页、时区、报告定义或授权参数，也不从管理分析导航选择推断项目。

数据库在每次目录访问中重新检查组织成员、项目成员和 `view_anonymous_analytics`。成功访问与一条不可变审计在同一事务中提交。审计保存精确授权证据、显式项目、完成时间和返回数量，但不保存快照 ID、报告元数据或报告格。runtime 只能执行一个固定的 `app_data` bridge，不能直接读取快照、授权或审计表。

固定排序不等于业务上的“当前”或“最新有效”。更正和取代语义尚未交付，因此调用方不得把第一项解释为未被取代的报告。单份快照读取仍使用 6L 端点，并独立重新授权和审计。Flutter UI、离线缓存、任意历史查询、图表、导出和报告发布不属于本决定。
