# 第一版问卷支持八类受控题型

场景问卷第一版支持八类题型：

- 是／否，可允许明确的“不适用”；
- 没有高低顺序的普通单选；
- 具有固定顺序的有序单选；
- 多选；
- 可区分整数或小数，并可配置单位、最小值和最大值的数字；
- 只表示某一天、不带时区的日期；
- 短文本；
- 长文本。

每个问题可以配置为必填或选填。文本答案默认不进入结构化统计，也不得用来绕过推广对象资料的存储与访问边界。文件上传、签名、矩阵表格、重复子表、任意公式和任意 SQL 不属于第一版问卷能力。

## Consequences

普通单选只能进行类别计数与比例分析，有序单选才可以使用顺序分布和中位等级，不得因界面上的选项排列而混淆两者。Flutter 与 SQL 按题型保留可验证的类型语义，不把所有答案压成无约束文本。
