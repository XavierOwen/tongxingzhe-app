# 个人兴趣中位等级使用较低的真实等级

状态：**已接受（2026-08-12）**。

关联：Issue #100、Slice 6W；ADR-0060、ADR-0061；`ANALYTICS-001`、
`ANALYTICS-002`、`ANALYTICS-006`、`ANALYTICS-007`、`ANALYTICS-012`。

## 决定

个人单次兴趣汇总继续以有效接触场次为统计单位。五档数量按 `0` 至 `4` 排序。
样本不为空时，中位等级是累计数量首次达到 `(总场次 + 1) ~/ 2` 的等级；样本
为空时，中位等级是 `null`。

偶数样本因此使用两个中间观察值中较低的真实等级。例如，四场接触的兴趣为
`1、1、4、4`，中位等级是 `1`，不是 `2.5`，也不会四舍五入成 `2` 或 `3`。
这个规则又称下中位等级。它只依赖等级顺序，不假设相邻等级距离相等。

`interest_distribution` v1 保持原有五档计数合同。新增
`interest_ordinal_summary` v1 承载五档计数、总场次和中位等级。个人结果继续标为
`localOperational + personalFact`，并带 UTC 期间、数据截止和接触场次同步覆盖。

## 后果与边界

个人分析页同时显示五档数量和中位等级，并说明这些事实只供本人回顾。页面不默认
显示兴趣算术指数，也不把中位等级解释成因果结果、绩效或团队排名。

本决定不定义比例、缺失状态或排除数量，也不改变管理报告、隐私抑制、对象当次
反应、关系阶段或后续联系同意指标。这些结果需要各自的版本化合同。
