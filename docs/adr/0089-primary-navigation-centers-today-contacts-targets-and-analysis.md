# 主导航围绕今日、接触、对象与分析

App 的稳定主导航只保留四个与核心任务直接对应的目的地：“今日”呈现本人的提醒、可选每周目标进度、近期行动与需关心的同步异常；“接触”容纳接触记录、草稿、补录、修订与作废；“对象”只展示本人有权跟进的推广对象、项目关系与待跟进事项；“分析”默认打开个人分析，只向拥有相应能力的成员显示匿名项目或组织汇总入口。该结构把产品中心放在“今天采取行动、如实记录、持续跟进、回看事实”，而不是管理员功能。

顶部始终显示“个人空间或组织 → 当前推广项目”上下文，所有主要页面都提供醒目但不占用第五个目的地的“记录接触”快捷操作。项目管理、问卷配置与成员权限从项目上下文菜单进入；账号、主题、语言、学习说明书与隐私设置从个人菜单进入，管理和设置不再与高频核心工作并列。

## Consequences

手机使用四项底部导航，平板、桌面和 Web 使用相同信息架构的侧边导航；屏幕宽度只改变导航容器和页面布局，不创建两套产品结构。深层链接与权限隐藏依然遵守当前项目上下文，无权用户不会因为导航或链接而看到内容摘要。
