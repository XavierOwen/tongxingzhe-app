# ADR-0151：管理报告保留遵循组织生命周期

- 状态：已接受
- 日期：2026-08-21
- 切片：Slice 6BF
- Issue：#197
- 需求：`ORG-004`、`ORG-005`、`ANALYTICS-013`、`ANALYTICS-041`、`PRIVACY-033`、`TEST-035`、`MANUAL-025`
- 相关决定：ADR-0036、ADR-0037、ADR-0074、ADR-0131、ADR-0150

## 背景

管理报告快照和 replacement lineage 采用追加不可变记录。该设计支持复算和审计，但不能让报告绕过账号或组织删除规则。现有规范给组织和账号删除各设三十天恢复期，却没有按报告年龄计算的独立保留期限。

授权撤回、更正版取代、账号删除和组织删除会产生不同结果。如果把它们都实现为 tombstone 或按报告年龄清理，系统会过早删除组织历史，或在组织删除后继续保留业务数据。

## 决策

管理报告没有独立的年龄保留期限。组织存在时，报告按组织业务数据保留。授权撤回只停止该成员的读取、发布和导出权限，不删除报告。更正版取代只改变明确的 replacement lineage，不删除旧快照。

账号删除恢复期届满后，组织拥有的报告继续保留。快照、发布和审计中的自然人归属必须改为不可反查的“已删除成员”，不能阻止账号身份清除，也不能保留可反查身份。

组织删除申请生效后的三十天内，仍获授权的成员可以读取已有报告。系统不得发布新报告、登记 replacement 或生成新的导出文件。组织在期限内恢复时，已有报告保持原状，不产生 tombstone 或清除资格记录。

组织删除恢复期届满后，Slice 7 的删除终结流程必须清除该组织所有 report family 的快照、报告正文、发布 provenance、replacement lineage，以及含业务内容的读取、目录和导出审计。系统只保留不含报告 ID、快照 ID、报告内容、成员身份或其他业务内容的最小组织删除审计。

清除必须失败关闭。只要在线数据或依赖无法完整清除，组织和报告就保持不可访问，不能恢复部分读取。logical tombstone 或 purge eligibility 只能证明访问门禁或清除资格，不能作为物理清除证据。

生产备份的具体保留期限、RPO 和 RTO 由部署评审决定。恢复副本在提供服务前必须重放已完成的组织删除事实，并证明已删除组织的数据不会重新出现。数据库 dump／restore 测试不能替代生产备份清除证据。

6BF 只固定产品、隐私和后续测试合同。它不新增数据库状态或删除入口。账号与组织生命周期、删除终结流程和恢复演练仍由 Slice 7 交付。

## 后果

- 后续删除实现必须覆盖全部 report family，不能只处理渠道报告。
- 删除实现不能复用 `view_anonymous_analytics`、`release_management_reports` 或 `export_management_reports` 作为清除权限。
- 清除前必须处理不可变快照、外键、replacement lineage 和含业务内容审计，不能关闭约束后直接删除。
- 在 Slice 7 的组织删除状态和受控终结流程存在前，不新增孤立 tombstone 或清除资格表。
