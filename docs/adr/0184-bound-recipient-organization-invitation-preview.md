# 仅绑定收件人可在入组前预览组织邀请

为让用户在接受前知道将加入哪个私有组织，经用户明确授权，已有账号邀请的绑定收件人可按已知 invitation UUID 在线读取组织名称与有效期。这是私有组织目录之外的受限例外，不开放组织搜索、成员资料或邀请收件箱；错误收件人和所有不可见邀请状态均使用同一个拒绝结果。

预览只观察仍可接受的邀请，不保留接受资格，不修改 claim、成员关系或审计。接受继续复用 [ADR-0180](./0180-organization-directed-account-invitation-contract.md) 的锁后授权与精确重放；已接受回执是历史事实，界面须重读当前组织目录。

成功预览允许返回组织名称，但不改变创建／接受回执、失败响应和日志的无名称边界。完整字段、权限与验证合同见 [Product Spec 的 Slice 7AA](../PRODUCT_SPEC.md#slice-7aa绑定收件人预览并确认接受组织邀请)。
